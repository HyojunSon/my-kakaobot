# HTS 카카오 차트 봇

## 짧은 메시지 표시

차트 분석은 반복 설명·긴 질문·손익비 설명을 줄이고 현재 흐름, 참고선, 살 때/팔 때/계획 재검토 기준을 짧게 표시합니다. 지수는 시장 관점 안내를 유지합니다. 긴 본문은 글자 수와 한글 자동 줄바꿈 예상 길이를 기준으로 짧은 말풍선으로 나눕니다. 실제 ‘전체보기’ 표시 여부는 카카오 앱의 화면 폭·글꼴·버전에 따라 다르므로 표시를 완전히 보장하지는 않습니다.

종목추천은 종목당 한 줄(이름·선과의 거리·반등 횟수)로 표시합니다. 추천이 매우 많으면 카카오 출력 3개 제한 때문에 `추천 이어보기` 버튼 또는 `/종목추천 2`로 나머지를 확인합니다. 다음 요청은 시세를 새로 조회하므로 결과가 달라질 수 있습니다. 오픈빌더에서 다음 페이지 명령도 같은 스킬로 전달되게 해야 합니다. 화면의 긴 텍스트 ‘전체보기’와는 별개입니다.

## 차트 규칙 분석

`/차트 종목명` 응답은 이미지와 규칙 분석 텍스트를 함께 제공합니다. 전일·최근 5거래일 변화율, 이전 20일 대비 거래량, 저장된 추세선/수평선의 현재 가격, 최근 봉의 선 접촉 및 0.2% 이상 종가 돌파/이탈 후보를 계산합니다. 선은 가격 위치에 따른 지지·저항 **후보**이며 과거에 검증된 역할로 간주하지 않습니다. 장중 일봉과 거래량은 미확정임을 표시합니다.

매수 검토 구간은 가장 가까운 하단 저장선 ±min(ATR14×0.25, 선가격×1%), 무효화 가격은 하단 선가격-max(ATR14×0.5, 선가격×1%)입니다. 가장 가까운 상단 선을 매도 검토 가격으로 삼고, 매수 구간 상단 기준 비용 제외 손익비가 1.5 이상일 때만 조건부 가격 시나리오를 제공합니다. 유효한 선·변동성이 부족하면 제안을 보류합니다. 예측 모델이나 수익 확률을 제공하지 않습니다.

분석용 시세 조회가 추가되므로 차트 블록도 콜백 활성화를 권장합니다. 콜백 URL이 있으면 먼저 수신 응답 후 분석 메시지와 이미지 URL을 콜백으로 보냅니다. 없으면 분석 후 일반 응답하며 5초를 보장하지 않습니다. 분석 메시지와 이미지 URL은 각각 조회 시점의 최신 시세를 사용하므로 장중 가격이 조금 다를 수 있습니다. 분석 실패 시 이미지와 분석 실패 안내를 제공합니다. 외부 AI 호출·키·과금은 없습니다.

## 추세선 근접 종목 조회

`/종목추천`은 동기화된 HTS 추세선 중 과거 캔들로 지지 역할을 확인한 후보만 대상으로 최신 종가가 선 위 0~1%인 종목을 출력합니다. 최신 봉을 제외한 최근 최대 60개 봉(추세선 첫 끝점 다음 봉부터, 최소 20개)에서 종가의 80% 이상이 선 아래 0.2% 허용 범위 위에 있고, 저가가 선 ±0.5%를 접촉한 뒤 선 위로 회복하고 이후 3개 봉 안에 해당 시점의 선보다 0.5% 이상 위에서 종가를 형성한 이력이 두 번 이상 필요합니다. 한 번의 방문을 중복 집계하지 않도록 반등 확인 봉 이후 최소 3개 봉 간격을 둡니다. 반등 전 선 아래 0.5% 이상 종가 이탈 시 해당 접촉은 인정하지 않으며, 직전 3개 봉 중 같은 이탈이 있거나 최신 가격이 선 아래이면 제외합니다. 기울어진 선은 매 거래일의 선 가격으로 비교합니다. 이는 통계적으로 검증된 예측이 아닌 보수적인 규칙이며, 저항 돌파 후 지지 전환도 충분한 이력이 쌓이기 전에는 제외될 수 있습니다.

여러 선에 해당해도 종목은 한 번만 표시하고 가장 가까운 유효 지지 후보의 이격률로 정렬합니다. 수평선과 KOSPI/KOSDAQ 지수는 대상에서 제외합니다. 시세 기준일, 조회 실패 및 계산 불가 선 개수도 표시합니다. 거래일 끝점이 시세 응답에 없으면 해당 선은 추정하지 않습니다. 과거 구간은 실제 체결이 완료된 봉만 보장하는 거래소 캘린더 판정 없이 최신 봉을 항상 제외하며, 현재 근접 판정에는 장중 변동 가능한 최신 일봉 종가를 사용합니다.

오픈빌더에 `/종목추천` 전용 블록을 만들고 기존 `/api/chat` 스킬 및 스킬데이터 사용을 연결하세요. 전체 종목 순회는 5초를 넘을 수 있으므로 **이 블록의 콜백을 활성화**하세요. `userRequest.callbackUrl`이 오면 서버가 `useCallback: true`를 반환하고 FastAPI BackgroundTasks에서 스캔 후 결과를 콜백으로 보냅니다. 콜백이 없으면 일반 응답으로 처리되며 5초 이내를 보장하지 않습니다. 콜백은 운영 채널에서 실제 검증해야 하며 현재 로컬 테스트는 외부 발송 없이 수행했습니다. 플랫폼이 응답 후 백그라운드 작업을 중단하는 환경에서는 별도 작업 큐가 필요합니다. Vercel 함수 실행시간은 스캔과 콜백 전송을 끝낼 만큼 확보해야 합니다.

`/차트 코스피`, `/차트 코스닥` 및 `/차트 KOSPI`, `/차트 KOSDAQ`도 지원합니다. 네이버 지수 OHLCV로 최근 6개월 캔들·EMA·거래량을 표시하며 지수값은 소수점 두 자리(pt)로 표시합니다. 이미지 주소는 `/api/chart/KOSPI.png`, `/api/chart/KOSDAQ.png`입니다. 지수 이름과 영문 코드도 엔티티 CSV에 포함되어 있으므로 CSV 재업로드와 서버 재배포 후 사용하세요.

## 오픈빌더 종목 엔티티 일괄 업로드

`data/stock_name_all.csv`를 `stock_name` 엔티티에 업로드합니다. 공식 샘플과 같이 헤더가 없으며 첫 열은 종목명, 이후 열은 각각 동의어입니다. 종목코드와 일부 별칭을 포함한 UTF-8 파일입니다. Excel에서 열어 재저장하면 코드 앞의 0이 사라질 수 있으므로 생성한 파일을 그대로 업로드하세요. KOSPI/KOSDAQ/KONEX 주식(우선주·스팩 포함)과 국내 상장 ETF를 포함하며 ETN은 제외합니다. ETF는 코덱스/타이거/에이스/라이즈/솔/플러스 등 브랜드 한글 별칭을 지원합니다.

최신 목록으로 재생성: 워크스페이스 루트에서 `stock_env\Scripts\python.exe my-kakaobot\export_stock_entity.py --refresh`.

ETF 목록만 갱신: `stock_env\Scripts\python.exe my-kakaobot\export_stock_entity.py --refresh-etf`. `data/etf_listing.csv`와 서버용 카탈로그도 배포에 포함합니다.

`data/stock_aliases.json`에서 코드별 별칭을 관리합니다. `export_stock_entity.py` 실행 시 CSV와 서버용 `data/stock_catalog.json`을 함께 생성합니다. 서버는 전체 카탈로그와 HTS 목록을 합쳐 코드·정식 이름·별칭으로 조회하며, 선이 없는 종목은 캔들과 EMA만 표시합니다. CSV에는 별칭 하나당 한 열을 사용하고, 공백·대소문자 정규화 후 다른 종목과 충돌하는 별칭은 제외합니다. 삼전/하닉/엘전 등 약어를 추가했으며 CSV 재업로드와 서버 재배포가 모두 필요합니다. HTS 선 갱신은 종목 카탈로그와 독립적입니다.

`/차트 이뮨온시아`, `/차트 424870`, `/차트 삼전` 명령에 최근 6개월 일봉과 HTS 추세선/수평선 이미지를 응답합니다. 정식 종목명·코드·등록된 별칭을 사용할 수 있습니다.

## 실행

워크스페이스 루트에서:

```powershell
stock_env\Scripts\python.exe my-kakaobot\sync_hts.py
stock_env\Scripts\python.exe -m pip install -r my-kakaobot\requirements.txt
cd my-kakaobot
..\stock_env\Scripts\python.exe -m uvicorn api.index:app --port 8000
```

Vercel 프로젝트 루트는 `my-kakaobot`입니다. `PUBLIC_BASE_URL`을 공개 HTTPS 배포 주소로 설정하고 카카오 스킬 URL을 `https://배포주소/api/chat`으로 지정합니다. 이미지 URL은 로그인/배포 보호 없이 접근 가능해야 합니다. 기존 `vercel.json` 라우팅을 사용합니다.

## 데이터와 이미지 처리

`sync_hts.py`는 `my_hts/data`에서 종목명과 드로잉만 읽고 `data/hts_snapshot.json`에 내보냅니다. 메모와 텔레그램 설정은 포함하지 않습니다. JSON 파일을 배포에 포함하세요. HTS 선을 수정한 후 동기화와 재배포가 필요합니다. 자동 원격 동기화는 아직 없습니다.

HTS 검색창에 `코스피`/`코스닥` 또는 `KOSPI`/`KOSDAQ`을 입력하면 지수 차트를 열어 기존 추세선·수평선 도구로 편집할 수 있습니다. 관심종목에도 추가할 수 있습니다. 지수 드로잉은 `my_hts/data/drawings/KOSPI.json`, `KOSDAQ.json`에 저장되며 동기화 스크립트가 같은 키로 내보냅니다. 지수 일봉은 봇과 동일한 네이버 소스를 사용하고 수평선은 0.01포인트 단위로 저장합니다.

웹훅은 요청별 고유 이미지 URL을 즉시 반환합니다. 카카오가 그 URL을 조회할 때 서버가 새 시세를 받아 PNG를 생성합니다. 다른 인스턴스에서도 동작하도록 이미지 메모리 캐시나 임시 파일에 의존하지 않습니다. 시세와 이미지는 요청마다 새로 생성합니다.

네이버 일봉 데이터의 최신 응답을 사용하며 거래소 실시간 피드가 아니므로 무지연 가격을 보장하지 않습니다. 이미지에 데이터 기준일과 조회 시각을 표시합니다. 기본 1,000개 일봉을 조회하고 오래된 추세선 끝점이 있으면 필요한 기간까지 늘립니다(최대 10,000개 요청). 응답 범위보다 과거인 끝점이 있으면 전체 조회로 재시도합니다. 화면에는 마지막 캔들 기준 6개월만 표시합니다. 데이터에 없는 선의 끝점은 추정하지 않고 제외하며 하단에 제외 수를 표시합니다. 이동평균은 HTS와 동일한 EMA 방식이며 조회 시작점에 따른 초기값 영향은 1,000개 이상의 과거 봉으로 줄입니다. 제공처의 수정주가/과거 데이터 정책이 바뀌면 저장된 선과 차이가 생길 수 있습니다.

렌더링은 캔들과 거래량을 각각 collection으로 묶고 PNG 압축 수준을 1로 낮춰 CPU 비용을 줄입니다. 이미지 해상도는 유지합니다. Vercel 로그의 `chart_timing`에서 `fetch_ms`, `lock_ms`, `render_ms`, `total_ms`, 이미지 크기를 확인할 수 있습니다. `request_timing`은 웹훅과 이미지 경로의 처리 시간을 구분합니다. 응답 `Server-Timing` 헤더에도 앱 처리 시간이 표시됩니다. 이 측정에는 함수 실행 전 플랫폼 콜드 스타트와 사용자까지의 전송 시간은 포함되지 않습니다. 완성 이미지와 시세 캐시는 사용하지 않아 요청마다 새 시세를 조회합니다.

웹훅 응답 시간과 이미지 표시 시간은 다릅니다. 이미지 생성 실패 시 카카오에서 이미지가 표시되지 않을 수 있으며 이미지 URL과 서버 로그를 확인해야 합니다. 실제 Vercel/카카오 환경의 콜드 스타트와 다운로드 제한은 배포 후 검증해야 합니다. 이미지 표시까지 5초를 보장하지 않습니다.

한글 표시는 함께 포함된 나눔고딕 `assets/chart-font.ttf`를 파일 경로로 직접 지정합니다. `assets/OFL.txt` 라이선스와 함께 두 파일을 배포에 포함하세요. 출처: Google Fonts 저장소의 `ofl/nanumgothic`. Matplotlib 캐시는 Vercel에서 쓰기 가능한 임시 디렉터리를 사용합니다.

## 테스트

봇 프로젝트 폴더에서 `python -m unittest discover -s tests -v`를 실행합니다. 네트워크와 실제 메시지 전송 없이 시세 파싱, 거래일 계산, PNG 생성, FastAPI 응답을 확인합니다. FastAPI 미설치 시 HTTP 테스트는 건너뜁니다.
